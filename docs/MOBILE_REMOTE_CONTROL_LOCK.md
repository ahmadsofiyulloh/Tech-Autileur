# Mobile Remote Control Layer Lock

## Purpose
The user must be able to operate and monitor the workflow from mobile.

## Locked Definition
Mobile Remote Control Layer means the PWA provides a mobile control hub. It does not build a custom remote desktop engine.

## Mobile Surfaces
- Dashboard summary.
- Products list and product detail surfaces.
- Controller queue and Flow tool pool.
- Output and import status.
- Settings hub access.

## MVP Features
- Open the controller queue from mobile.
- Open the Flow link from mobile.
- Open the Drive batch folder from mobile.
- Copy the next prompt from mobile.
- View today's batches and ready prompt packs.
- Mark batch running or imported.
- View import status.
- Review clips from output/history surfaces.
- Approve or reject clips.
- Attach final video Drive URL.
- Open upload package metadata.

## User-Only Setup
The user must choose, install, log in to, and test the external remote desktop app.

## Out of Scope
- Streaming desktop video inside the PWA.
- Building custom remote desktop protocol.
- Auto-clicking Google Flow.
- Remote control of TikTok/Shopee upload.
