# Mobile Remote Control Layer Lock

## Purpose
The user must be able to operate and monitor the workflow from mobile.

## Locked Definition
Mobile Remote Control Layer means the PWA provides a mobile control hub. It does not build a custom remote desktop engine.

## MVP Features
- Mobile dashboard.
- Open remote desktop link.
- Open Google Flow link.
- Open Google Drive batch folder.
- Copy next prompt.
- View today's batches.
- Mark batch running/imported.
- View import status.
- Review clips.
- Approve/reject clips.
- Attach final video Drive URL.
- Open upload package.

## User-Only Setup
The user must choose, install, log in to, and test the external remote desktop app.

## Out of Scope
- Streaming desktop video inside PWA.
- Building custom remote desktop protocol.
- Auto-clicking Google Flow.
- Remote control of TikTok/Shopee upload.
