# FAQ

## Versi app

**Di mana versi app terlihat?**  
Di footer shell authenticated dan di menu `Settings > Tentang`.

**Apa arti build number?**  
Itu nomor rilis app dengan format `YYYY.MM.DD.N`.

**Kapan versi dinaikkan?**  
Saat ada rilis formal atau bundel perubahan yang siap dipakai operator.

## Formalisasi

**Apakah ada sertifikat resmi?**  
Belum ada. Paket formal saat ini mencakup versi app, copyright, About page, dan changelog.

**Kenapa versi prompt tidak sama dengan versi app?**  
Karena versi prompt/share/history adalah versioning data domain, bukan versi rilis aplikasi.
